# Heart_Disease_Analysis
# Project Overview
A healthcare analytics project leveraging Python to analyze 303 patient records for cardiovascular disease risk factors. The project examines clinical metrics—such as chest pain type, cholesterol, resting blood pressure, and maximum heart rate—to identify key physiological indicators associated with heart disease.

# Key Insights
Chest Pain Severity & Risk: Asymptomatic chest pain (cp = 0) shows a strong association with positive heart disease diagnoses, serving as a primary observational marker.

Exercise Capacity: Patients exhibiting higher maximum heart rates (thalach) during stress testing show a lower frequency of heart disease, whereas lower exercise tolerance correlates with elevated risk.

Business & Healthcare Impact
Data-Driven Diagnostics: Translates raw physiological data into actionable statistical patterns to support clinical decision-making workflows.
